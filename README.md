# Biologie_Osmose

Escape-Spiel „Mission Kirschernte“ für Biologie, Jahrgang 10 (45 Minuten, Partnerarbeit): Osmose, hypo-/hyper-/isotonische Lösungen, Turgor, Plasmolyse und die Planung eigener Versuche.

Das Spiel steckt vollständig in `index.html` und läuft im Browser. Der Fortschritt wird nur lokal im Browser gespeichert.

Auf der Website mathe-koenner liegt eine Kopie unter `apps/mission-kirschernte/`, weil dieses Repository privat ist.
